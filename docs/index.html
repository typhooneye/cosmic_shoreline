Cosmic Shoreline

Cumulative atmospheric loss calculator

Due to the nonlinear dependence of hydrodynamic escape on XUV flux, lower cumulative XUV does not necessarily mean lower cumulative atmospheric loss.

Star & Planet Input

Input Numbers

Enter one value or comma-separated arrays. When using arrays, `st_mass`, `pl_masse`, `pl_radiuse`, and `pl_orbsmax` should have the same length so the calculator can evaluate planets one by one.
Numbers only. Single value or comma-separated array.
Leave blank to infer radius from the mass-radius relation.

Input Planet Names

Enter one or more planet names. The data will be read from `NASAExoArchive_2025-02-28_aggregate.csv`, with planetary masses inferred using the workflow in `03-21-25-Model-CS-Figures.ipynb`, section `2.2 Cosmic Shoreline: Planetary Mass`.
Comma-separated or newline-separated list.

Rocky Samples

Plot rocky planets below the radius valley, following the criterion described in Ji et al. 2025.

Atmosphere (select one or more)

`N₂/O₂ (N22)` and `H₂O` apply only to 1 Earth-mass planets.
Enter a JS-style expression for escape rate in `kg/s` as a function of `F_xuv`. Available variables: `F_xuv`, `pl_masse`, `pl_radiuse`.
Example: `1e6 * Math.pow(F_xuv, 0.5)`

X-ray model (select one or more)

LX = k · L₀ · tidx  (t in Gyr, L₀ in erg s⁻¹)
Defaults: Lammer et al. 2009 (M dwarfs)

Each field accepts a comma-separated array

EUV Extrapolation

Use the King & Wheatley 2020 scaling based on solar data, with separate relations for soft and hard X-ray emission:
LEUV/Lbol = β (Lbol/As)γ (LX/Lbol)γ+1
Use a custom single power-law EUV extrapolation:
LEUV/Lbol = β (Lbol/As)γ (LX/Lbol)γ+1
