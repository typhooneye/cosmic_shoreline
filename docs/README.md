# Web Tool

This folder contains a calculator for cumulative atmospheric loss.

## Files

- `index.html`: main user interface and plotting logic
- `web_data.js`: bundled interpolation data and planet/sample tables used by the webpage
- `main.js`: older JS scaffold kept for reference

## Usage

Open `index.html` in a browser. Or use this link: https://typhooneye.github.io/cosmic_shoreline/

## Scope

The tool supports:

- manual planet/star input
- named-planet lookup from the bundled archive-derived table
- rocky-sample plotting
- multiple atmosphere selections
- multiple X-ray models
- cumulative XUV and cumulative atmospheric-loss comparison plots
