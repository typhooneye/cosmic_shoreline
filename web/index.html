The Cosmic Shoreline Informed by Hydrodynamic Escape

Input

Planet source and parameters

Earth defaults

Defaults are set to Earth. If either planetary mass or radius is omitted, the other is estimated from the Zeng et al. 2019 rocky mass-radius relation.

Current defaults: label Earth, star mass 1.0 Msun, system age 4.54e9 yr, planet mass 1.0 Mearth, planet radius 1.0 Rearth, orbital distance 1.0 AU.

Constants used in cosmic_shoreline.py for the preview: Earth mass 5.972e24 kg, Earth radius 6.371e6 m, Earth escape velocity 11.186 km/s.

Example array formats: 0.5, 1.0, 2.0 or [0.5, 1.0, 2.0]. Use NaN for a missing mass or radius that should be inferred.

No extra input fields are shown here. This mode will use the rocky planet sample from Ji+2025 directly.
